안녕하세요. 

2017년부터 시작하여 어느덧 다섯 번 째 회고가 되었습니다. 

2021년은 2020년의 연장선과도 같은 해였습니다.
주중에는 회사 업무를 하고 주말에는 개인적인 공부를 해가며 나름 알찬 나날을 보냈다고 생각됩니다.
내년에도 올해와 비슷한 패턴의 날들이 지속될 것 같지만, 새해는 언제나 기대됩니다.

## 회사 근무

커머스 관련 스타트업에서 데이터 엔지니어로 근무한 지 만 3년이 되어가고 있습니다.

서당개 3년이면 풍월을 읊는다는 말처럼, 3년 정도 회사생활을 하다 보니 일에 대한 노하우도 쌓이고 보다 넓게 볼 수 있는 안목도 생기는 것 같습니다.
특히 올해는 새로 입사하신 팀원들과 열심히 합을 맞추면서 업무를 추진하다보니 일에 대한 재미도 많이 느꼈고 겪으면서 배운 것들도 많이 있었습니다.

## 블로그

올해는 파이썬, docker, azure 등의 주제로 6개의 블로그 글을 작성했습니다.

1일 1블로그를 목표로 했던 때에 비해서는 확연히 적은 수의 글이지만 알찬 내용이 될 수 있도록 신경을 썼습니다.
내년에는 게시 횟수를 늘리면서도 내용 또한 유익할 수 있도록 노력하겠습니다.

## ML-For-Beginners

마이크로소프트에서 오픈소스로 공개한 Web Development for Beginners 후속으로 나온 ML for Beginners 입문서를 번역했습니다.

주로 퇴근 후나 주말에 작업을 해야됐기에 속도가 더디고 힘들었지만, 꾸준히 해보면서 보람을 느꼈습니다.
이번 입문서 역시 챕터 구성이 좋아서 누구나 부담없이 읽어볼 내용이라고 생각됩니다.

## notion database

현재 근무하고 있는 회사에서 노션을 적극적으로 도입해서 차근차근 알아가던 도중에, 개인 계정으로도 노션을 사용하게 되었습니다.
노션을 사용하다가 공식 API와 통합 봇이 나와서 파이썬 구현체를 만들어보고 싶었습니다.
노션 API 스펙 중에 데이터베이스 기능 위주로 파이썬 코드를 작성해서 패키지로 PYPI에 배포했습니다.

```
깃허브 : https://github.com/minwook-shin/notion-database

PYPI : https://pypi.org/project/notion-database/
```

지금 시점에 아직 40 스타를 받은 신생 오픈소스 프로젝트이지만, 계속 추가되는 노션 API 스펙을 따라가면서 코드 리펙토링을 계속 진행할 예정입니다.
많은 스타와 관심 부탁드립니다 :)

## 오픈소스 커뮤니티

올해도 작년과 마찬가지로 우분투 한국 커뮤니티 l10n 컨트리뷰션팀을 맡아서 활동했습니다.

틈틈이 새로 올라온 한국어 번역이나 갱신된 번역을 확인하면서 20.04.2 언어팩 테스트 일정과 21.10 Freeze 소식도 메일링으로 공유하는 등 
소소하게 커뮤니티 활동을 지속하고 있습니다.

내년에 출시할 우분투 22.04 LTS 버전의 UserInterface Freeze 일정에 맞추어서 번역 활동을 계속 이어갈 예정입니다.
